# Rock-Paper-Scissors Game

## Overview
This is a simple Rock-Paper-Scissors game built using HTML, CSS, and JavaScript. Players can choose between Rock, Paper, or Scissors, and the computer will make a random choice. The winner is determined based on the classic game rules.

## Features
- Interactive UI with buttons for player selection.
- Randomized computer choice.
- Real-time result display.
- Basic animations and styling.

## How to Play
1. Open the game in a web browser.
2. Click on Rock, Paper, or Scissors to make your choice.
3. The computer will make its choice randomly.
4. The result (Win, Lose, or Draw) will be displayed.

## Technologies Used
- **HTML**: Structure of the game.
- **CSS**: Styling and animations.
- **JavaScript**: Game logic and interactivity.
